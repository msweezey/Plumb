Three levels of autonomy

Every task, run three ways.

The same job behaves differently depending on where the human sits. We score all three, so you can see how far each platform lets you hand over.

HumanSaaS + AI

Level 1

Human in the loop

A marketer works in the platform's own UI with its built-in AI features. The human drives every step.

Measures: how much the AI features save a skilled operator.

HumanAgentMCP

Level 2

Human on the loop

A marketer operates from an IDE or an AI assistant, calling the platform through its MCP server. The human approves and steers.

Measures: tool coverage, accuracy and how often the human has to step in.

HumanAgentMCP

Level 3

Human out of the loop

Agents get the task and run it on their own. A human sees the outcome, not the steps.

Measures: end-to-end success, cost and whether it can write without breaking things.

How an eval works

Real jobs. Real accounts. Graded by pros.

01

Task library

Real marketing-ops jobs across B2B and B2C, enterprise down. Chosen by the practitioner boards.

  • Build a 3-email nurture
  • Pause last month's losers
  • Clone and localize a campaign
  • Route a lead form
  • Clean 500 contacts
02

Harness

Several AI models × each platform's MCP server × a sandbox account. Same tasks, same models, every platform.

  • 4 models
  • MCP server
  • Sandbox account
  • 3 runs per combo
03

Scoring

Machine-measured on the run, then the final output is graded by practitioners in that discipline.

  • Success
  • Accuracy
  • Tool calls
  • Cost
  • Time
  • Interventions
  • Read / write coverage
  • Safety
04

Output

The headline goes on the Index. Behind it sits the full eval set, every step broken out, and a forkable Plumb Line so you can adopt the play.
