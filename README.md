# Plumb

Plumb builds and runs the software a business depends on, on a monthly retainer: a managed service provider that has moved up the stack from infrastructure to custom applications.

This repository holds the Plumb business material: positioning, offer, pricing and supporting notes.

## Contents

- `design/` — Plumb brand and UI explorations
- `harness/` — retail brand test harnesses (Pact, M.M.LaFleur, Edikted, Topo Designs); see `harness/README.md`
- `docs/notes/` — build and test write-ups for the retail harnesses
