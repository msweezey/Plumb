## Notes

- `*.dc.html` files are design-canvas artboards. They use inline styles and open in a browser, though the `./support.js` runtime they reference only exists inside the Claude design canvas.
- `canvas.json` records artboard order and the linked design system for each canvas.
- Brand names in the UI mockups (Glossier, Rare Beauty, CeraVe and others) carry **invented, illustrative scores**. Replace them with real Index data or fictional brands before anything is published.
